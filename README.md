# Playwright Modern Project Template

This project is a powerful boilerplate for API and UI test frameworks.

It uses modern Playwright features and clean design patterns. The goal is to help teams start fast, keep tests easy to read, and grow the project without chaos.

## What Is Inside

- API test structure
- UI test structure
- Page object structure
- Helper structure
- Visual test placeholders
- Accessibility test placeholders
- Performance test placeholders

## Why Use It

This template gives you a strong base for a modern test project. You can use it for web UI tests, API checks, visual checks, accessibility checks, and performance checks.

The project is made to be simple, clear, and ready for real work.
